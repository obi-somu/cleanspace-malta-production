# CleanSpace Malta Website Operating Specification

## Roles applied

The website should be maintained using the combined perspective of:

- UX/UI designer
- Conversion-rate optimisation specialist
- Front-end developer
- Mobile accessibility reviewer
- Local SEO strategist
- Service-business copywriter
- Privacy-aware web publisher
- Performance and deployment engineer
- QA reviewer

## Design system

- Primary palette: deep navy, clean white, restrained teal.
- Visual tone: professional, calm, local, credible and uncluttered.
- Typography: native/system sans-serif for speed and consistency.
- Layout: generous but not excessive spacing, strong information hierarchy, clear mobile behaviour.
- Photography: realistic clean residential interiors; no fake staff photos or AI-generated people presented as employees.

## Conversion rules

- WhatsApp is the primary CTA.
- Price language must always distinguish a starting guide from a confirmed quote.
- Service scope and location must be confirmed before an appointment.
- Do not fabricate testimonials, client counts, star ratings, certifications or legal status.
- Repeat the primary CTA at high-intent points without making the page feel aggressive.

## Content rules

- Use plain, professional English.
- Keep the primary service area focused on Malta.
- Prioritise rooms, studios, shared apartments, small flats, move-in / move-out cleaning, kitchens and bathrooms.
- Describe the service as appointment-based while capacity is still being validated.
- Update legal/privacy copy whenever data collection, analytics, online forms or payment processing are introduced.

## Technical rules

- Keep the site static unless a real need for a framework emerges.
- Keep JavaScript non-essential to core content.
- Maintain keyboard-accessible navigation and semantic headings.
- Optimise image sizes before publishing.
- Avoid third-party trackers until there is a defined analytics/privacy requirement.
- Deploy from Git to Netlify and use the repository default branch as the production branch.
